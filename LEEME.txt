# Catálogo web DaCam

Este catálogo está preparado para publicarse gratis con GitHub Pages.

## 1. Personalizar los datos
Abrí `script.js` y:
- Reemplazá `WHATSAPP_NUMBER` por tu número con código de país, sin `+`, espacios ni guiones. Ejemplo de formato argentino: `54911XXXXXXXX`.
- Editá los productos dentro del arreglo `products`.
- Para cada producto, completá `name`, `category`, `price`, `description` e `image`.

## 2. Agregar fotos
Subí las fotos a la carpeta `assets`. En `image` escribí, por ejemplo:
`assets/mi-producto.jpg`

Usá nombres simples, sin espacios ni tildes. Si dejás `image` vacío, se muestra una tarjeta de ejemplo.

## 3. Publicar en GitHub
1. Entrá a https://github.com e iniciá sesión.
2. Creá un repositorio nuevo, por ejemplo `catalogo-dacam`.
3. Subí `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
4. En el repositorio, entrá a **Settings → Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**.
6. Seleccioná la rama `main` y la carpeta `/ (root)`, luego guardá.
7. Esperá unos minutos. GitHub te mostrará el enlace público del catálogo en esa misma sección.

## Importante
El catálogo no procesa pagos ni guarda pedidos: cada botón abre WhatsApp con un mensaje preparado. Podés cambiar textos, colores y productos cuando quieras.
